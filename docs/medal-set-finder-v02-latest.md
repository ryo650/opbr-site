# Medal Set Finder v0.2 — Recently Added Medals quick start

## Purpose

Make it easy to check combinations with newly cataloged medals without
scrolling the full ~700-medal collection or curating new sets by hand.

## User-facing behavior

- On **Medal Sets → Set Finder**, before the first medal is selected,
  show a compact **Recently Added Medals** panel.
- Each card displays medal artwork, name and **Find combinations**.
- Clicking a card puts that medal in Slot 1 and invokes the **existing**
  step-by-step candidate search for Slots 2 and 3.
- Clear the current catalog-only browse filters and search text when using
  this shortcut, so a previous first-medal filter cannot accidentally hide
  matching partners. Keep the user's three-medal comparison criteria (Tag /
  Trait / Hybrid, common-tag minimum, purpose) unchanged.
- The panel disappears when a medal is selected, and returns when all
  slots are cleared. Individual remove, Reset, search, filters and Builder
  transfer are unchanged.
- At most eight additions are shown, newest **catalog addition first**.
  Fewer than eight is expected when fewer are confirmed.

## Reliable automatic updates, without per-medal maintenance

- Source: `src/data/medals/medals.ts`, which is generated by the existing
  incremental importer. `mergeProductionMedals` retains all existing items
  in order and **appends** new confirmed medal IDs.
- The original 698 medals have no verified addition/release timestamps;
  showing the last eight from those 698 would pretend to know chronology.
- [Commit 774021265d7f307abdcfd60b1c0c816441b216ee](https://github.com/ryo650/opbr-site/commit/774021265d7f307abdcfd60b1c0c816441b216ee)
  verifies the 2026-10-01 catalog addition of `halloween-perona` and
  `ill-trick-you`. The helper anchors to that consecutive pair,
  and returns the appended suffix in reverse order.
- As more medals are appended by the existing importer, the panel
  automatically updates with no separate Set Finder entry or set curation.
- If the two anchor IDs are missing or out of order, show no shortcut items
  rather than confidently label unknown medals as recent.
- **"Recently Added" means added to OPBR Guide, not latest released in
  OPBR.** No release date or guessed `releasedAt` is introduced.
- If future workflows change from append-only to automatic sorting/reordering,
  replace this approach with an explicit audited `addedAt` metadata store.

Manually check mobile and desktop Preview:
1. Panel visible at initial Slot 1 with the two confirmed additions.
2. Tap a recent medal, verify Slot 1 and dynamic Slot 2 candidate list.
3. Complete a set, then remove the chosen medal and Reset to see the panel.
4. Apply browse Filters then tap shortcut: browse Filters reset while
   three-medal tag/trait comparison settings remain unchanged.
5. Confirm Builder link works after three selections.

This change does not alter the production medal DB, game release dates,
manual Featured Sets, routing, or set ranking. Do not merge/deploy without
verifying Preview.
