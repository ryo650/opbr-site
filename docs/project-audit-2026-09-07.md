# プロジェクト監査・修正記録

調査開始：2026-09-07、最終確認：2026-09-08（JST）。既存の配色、ページ構成、英語コンテンツを維持する方針で実施。確率入力値は所有者の指示により据え置き。

## 構造と対象範囲

Next.js App Router、React、TypeScript、CSS Modules、Tailwind、Radix UI。サーバーAPI・認証・DBはなく、TypeScriptの静的データを利用するファンサイト。Vercel Analyticsを使用。

357キャラクター（元は同一キャラの重複を含む358件）、12ガチャ、2キャラクターガイド、4時点の使用率データ。公開対象22ページ、準備中4ページ。主なクライアント機能はTier表作成、ガチャ抽選、使用率グラフ、目次と動画制御。大部分は静的生成、ガチャ一覧のみリクエスト時に期間判定。

コード・設定・データ参照・配信アセット・ビルド結果・実ブラウザを調査。ゲーム内性能や手動入力された数値の公式資料との全件照合は実施していない。

| P2 | 月末から1か月戻す処理で月が繰り上がり、グラフ期間が短くなる | 月末にクランプ。平年・閏年のテストを追加 |
| P2 | 全キャラクターデータが使用率グラフへ不要に混入 | サーバー側のデータ検証・ランキング作成を `processing.ts` へ分離 |
| P3 | 連続抽選で毎回全キャラを走査 | `createScoutRoller` で候補を一度だけ準備。個々の設定値の正規化ルールは維持 |
| P3 | 動画が画面外でもメタデータを先読み | preloadをnoneへ変更。表示領域に入った場合の既存再生処理と操作パネルを維持 |
| P3 | キーボードの本文スキップなし、隠れたヘッダーへのフォーカス、スキルタブの関連付け不足 | スキップリンク、フォーカス時のヘッダー表示、メニューの復帰、タブのID・パネル関連・矢印/Home/End操作を追加 |

不正なキャラクターIDは所有プロパティ確認と `notFound()` で拒否。更新後Next.jsの `dynamicParams=false` は不明IDで404を返す一方 `NoFallbackError` をログ出力したため、既知ページの静的生成を保ちつつ明示的な `notFound()` に統一。再検証で404応答を確認し、その後のサーバーログに同エラーは出ていない。

ローカル本番サーバーをCodex内ブラウザで確認。26ページと404を390px・1280pxで検査し、合計54画面でページ全体の横はみ出しと自動判定可能なWCAG違反は0件。axe-core 4.11.4をローカル監査プロキシ経由で読み込んだ。監査コードは製品に含めていない。

目視・実操作ではホーム、Tier表、ガイド、使用率、ガチャ、Tier作成を確認。Tier表作成の検索、配置、未分類への復帰、デスクトップのドラッグ＆ドロップ、Enter、Tab/Shift+Tab、Escape、フォーカス復帰、目次の選択を確認。ガチャは単発＋11連で12回・55ダイヤ・結果11体、対象まで抽選、リセットを確認。使用率は検索、フォーカス、期間切替、日付詳細、詳細の閉じる操作を確認。

**検証の限界**：自動検査の `color-contrast`、一部 `aria-prohibited-attr`、`video-caption` は要目視判定。Tierボタンの文字色を読みやすくしたが、全ての背景・状態のコントラスト適合を保証するものではない。実機のタッチドラッグ、複数ブラウザ、スクリーンリーダー、将来用のタブ形式データ、障害注入によるエラー再試行、実利用者のCore Web Vitalsは未検証。

## パフォーマンス

Node 22.12.0で、同じキャラ辞書・固定乱数を使う1,000回抽選を9回測定した中央値は **3.31ms → 0.47ms**。候補準備を含む純粋な抽選処理の比較であり、ページ全体や実機の体感速度を表す数値ではない。

本番HTMLから参照されるJavaScriptファイルを重複除外し、ファイルごとにgzipした合計（画像・CSS・後から読むチャンクは含まない）：

| ページ | 修正前 | 修正後 |
|---|---:|---:|
| ホーム | 214,819 B | 219,781 B |
| 使用率 | 232,137 B | 225,047 B |
| Tier表作成 | 231,556 B | 236,649 B |
| マーズのガチャ | 229,745 B | 234,779 B |

使用率は約7.1KB減った一方、他ページはフレームワーク更新・復帰UI等を含め約5KB増えた。全面的な軽量化とはしていない。Tier表作成HTMLは370,425 Bから386,931 Bになり、357体を全てDOMに出す構造は残る。画像は遅延ロードされるが、今後の追加でDOM量・操作負荷が増えるためページ分割や仮想化を検討する。

public全体は約64MB。最大の動画は約12MBだが、未使用素材も含むため初回転送量とは異なる。使用中動画の再エンコード・ポスター追加、不要アセット整理は、画質と素材保持方針を決めてから行う。

## 残った課題と次の作業

1. **取込ツールの競合方針を決める**：`core.mjs`・`core.test.mjs`・`import.mjs` の保持／削除を確認。保持するなら同じ版の依存ファイル・fixturesを揃え、独立テストを再実行する。内容を推測して補完したり、競合を自動解消したりしていない。
2. **ガチャ数値の確認**：所有者の希望どおり後回し。正規化されるため、例えばマーズの設定0.2%は現在約0.215%。合計はマーズ93、白ひげ93、OPDay92.85、ルフィ92.9、ルッチ93、ドレスローザ93、カク93、ゼファー93、サボ100.7、リンリン100、クザン99.6、ボニー99.6%。既存の「in-game rates」という説明と数値の不一致は残る。
3. **コンテンツの整合性**：最新使用率は100人に対して201枠、coverage100.5%。手動集計の注意書きはあるが、元データを再確認する。マーズのEarly Guide表記、準備中の4ページ、Tierの更新日・キャラクター名の表記揺れも編集上の確認が必要。
4. **Tier表の保存・共有仕様**：再読み込みで配置が消え、ホームの「Build and share」に対応する共有機能はない。ローカル保存・画像出力・共有URLのどれを提供するか決める。
5. **抽選統計の仕様**：`Pull Until Featured` は既存統計をその実行結果で上書きする。累積すべきか、独立試行とするかはUI文言を含めて決める。今回この挙動は維持。
6. **運用と検証**：Node 24 LTS等への環境統一、CIへのlint/test/build追加、実機タッチとスクリーンリーダー検証、実環境のLCP/INP/CLS計測。今回の環境はNode22.12で動作したが、一部開発依存は22.13以降を要求する警告がある。
7. **保守性**：長い1行のTSX/CSS、重複した情報ページのCSS、自由文字列のID、公開ガチャ期間に関係なく全マスターを参照する通常抽選候補、未使用素材、フォントの外部取得依存が残る。大規模な整形・アーキテクチャ変更は今回行っていない。

サイト本体の修正はローカルの未コミット差分。デプロイは行っていない。取込ツールのGit競合が残るため、その解消方針を決めてからコミットすること。
